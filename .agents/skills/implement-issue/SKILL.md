# Реализация Issue

Используйте этот навык только по явному запросу пользователя реализовать конкретную Issue. Навык описывает рабочий процесс и не является отдельным автономным агентом.

## Входные данные

- номер или URL Issue;
- репозиторий, если он не следует из текущего workspace;
- дополнительные ограничения пользователя.

Если Issue не определена однозначно, запросите её номер или URL. Перед изменениями прочитайте Issue, корневой `AGENTS.md`, связанные задачи и актуальное состояние `main`.

## Шаги

1. Сверьте цель, критерии приёмки, зависимости и ограничения Issue. Убедитесь, что обязательные предшествующие задачи завершены.
2. Создайте отдельную feature-ветку от актуального `main`. Одна Issue должна соответствовать одной ветке и одному PR.
3. Измените минимальный объём production-кода и документации, необходимый для критериев приёмки. Не добавляйте предположительную функциональность.
4. Добавьте или обновите тесты, которые проверяют реальное поведение. Для интеграции с базой используйте PostgreSQL Testcontainers, а не базу в памяти.
5. Выполните проверки из `AGENTS.md`. Не пропускайте неуспешные тесты и не заявляйте о проверках, которые не запускались.
6. Просмотрите diff на лишние изменения и секреты. Зафиксируйте изменения коммитом на русском языке.
7. Отправьте feature-ветку и создайте PR в `main` на русском языке. Укажите связь с Issue, решения, фактические проверки и ограничения. Дождитесь CI, если он запущен, и обновите PR результатом.

## Границы ответственности

- Не выполняйте merge, auto-merge, approve и прямой push в `main`.
- Не объединяйте несколько независимых Issues в один PR.
- Не скрывайте инфраструктурные ошибки и непройденные проверки.
- Не меняйте требования Issue без явного согласования с пользователем.
- Решение о принятии и слиянии остаётся за человеком.

## Выходной формат

Сообщите:

- ссылку на PR и имя ветки;
- краткий перечень изменений;
- команды проверок и точные результаты, включая число тестов, ошибок и пропусков;
- известные ограничения и оставшуюся работу;
- явное подтверждение, что merge и auto-merge не выполнялись.
